## Installation

Copier le dossier dans `~/.claude/skills/radar-avant-garde/` (ou `.claude/skills/radar-avant-garde/` d'un projet), en gardant le fichier `SKILL.md` a la racine du dossier.

Le skill s'active tout seul quand la demande correspond a sa description (premier bloc de `SKILL.md`).
